# LLD: Consistency checker (`engine/src/check/check.ts`)

## Principle

The checker reads **only** `world.sqlite`. It shares no code or memory with the simulation or the archive, so it is an independent audit: the database must prove its own consistency. It runs on every build (`npm run build:data` writes `build/check.json`), as `npm run check`, and in CI, where any violation fails the deploy.

## Invariants

| Id | Invariant | How |
|---|---|---|
| `causes-precede` | Every cause is dated no later than its effect | `event_causes` ⋈ `events` |
| `causes-acyclic` | Causes are recorded before their effects (id order), so the cause graph is a DAG | `cause < event` |
| `event-spans` | Every event ends no earlier than it begins | `end_year ≥ year` |
| `territory-ordered` | Territorial changes are logged in chronological order, never before their causing event | scan `territory_log` by `seq` |
| `territory-owner-alive` | Territory is only ever held by a polity that exists at that date | `born ≤ year ≤ died` |
| `territory-replay` | Replaying the territory, culture and religion logs over `initial_state` reproduces `final_state` exactly | full replay |
| `treaty-cessions` | Every district a treaty cedes changes hands at the treaty date, to the beneficiary, under that treaty's event | `events.data.terms` vs `territory_log` |
| `lifespans` | Every person dies after being born and holds offices only while alive | `persons` ⋈ `roles` |
| `reigns-disjoint` | No polity has two heads of state at once (the same person re-titled is not an overlap) | sort roles per polity |
| `no-anachronism` | No document mentions a person, place, state, faith, god, coin, house, script, language, people or event that did not yet exist | every `[[id\|…]]` link in the text part of `artifacts.body` (before the first `\n---\n`; the editorial apparatus after it may look ahead) |
| `authors-alive` | Every document was written by a person alive and at least 12 years old at its date | `artifacts.author` ⋈ `persons` |
| `script-language-exist` | Every document is in a language and script that existed at its date | `languages.born`, `scripts.born` |
| `ledger-prices` | Every ledger price is within 20% of the simulated market price for that place, good and decade | `artifacts.data.entries` vs `prices` |
| `links-resolve` | Every link resolves to a page, and every page's backlink count equals the links that point at it | `links` ⋈ `pages` |
| `citations-resolve` | Every catalogue number a document cites (`PAL·XX·NNNNN`) exists, and was written no later than the citing document | text part of `artifacts.body` vs `artifacts.catalog`, `year` |

## What it does not (yet) check

- **Prose.** A flagship's unlinked text could mention a later event. This is mitigated by dossiers cut at the document's date, fact-checking agents, and the ingestion validator.
- **Name forms.** These are generated by the language engine by construction.
- **Biased numbers.** Chronicle claims are deliberately false. They are recorded as claims and compared with the truth in the atlas.

## Testing the checker

`engine/test/checker.test.ts` writes a short world, asserts it passes, then corrupts one cause so it is dated 10,000 years after its effect. The test asserts that `causes-precede` reports the violation.
