# 0007: Product name "Palimpsest", repo "civilization"

**Context.** The owner created `~/projects/civilization`. A prior-art scan found "Palimpsest" used by tabletop games and academic projects, but by no software world generator.

**Decision.**
- The repo and folder stay `civilization`.
- The product is called **Palimpsest**: a manuscript scraped and written over, layer on layer, like the archive.
- The world itself is named by its own editorial language.

**Why.** The name is evocative and accurate. The generated world name keeps the title distinctive in search.
